## 3 Main lessons

- **Don't Repeat Yourself (DRY):** Avoid duplicating code by using functions or classes.
- **Single Responsibility Principle (SRP):** Each function and class should have only one clear responsibility for 
easier testing and improve code maintainability.
- **Meaningful Names:** Using descriptive variables, function and class names help to clearly communicate their 
purpose and avoid confusion.
